# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository when available. Do not publish exploit details, credentials, private files, or sensitive user information in a public issue.

For ordinary non-sensitive website bugs, open a GitHub issue with the affected page, browser, and reproduction steps.

## Release integrity

Published desktop downloads have SHA-256 checksums on the site's `/checksums` route and in `public/downloads/SHA256SUMS.txt`. Release files and checksum records must be updated atomically.
