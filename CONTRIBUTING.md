# Contributing

Contributions should preserve OrbitDrop's privacy-first architecture and accessible, responsive presentation.

1. Open an issue describing the proposed change.
2. Keep product claims aligned with the current native release.
3. Do not add analytics, cookies, tracking pixels, accounts, upload features, or user databases.
4. Run `npm run lint` and `npm test` before opening a pull request.
5. Update release names, checksums, help content, and verification commands together when publishing a desktop release.

Never commit credentials, environment files, unpublished installers, or user data.
